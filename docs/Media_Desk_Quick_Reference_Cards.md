# FLAG Church - Media Control Desk Quick-Reference Cards
**Church:** Full Life Centre AG Church (FLAG)  
**Usage:** Print, laminate, and tape these cards directly to the media control desk and camera rigs for instant operational guidance during live services.

---

## 🟥 CARD 1: Video Director & Switcher Cheat Sheet
*(Tape directly beside the ATEM Mini / vMix keyboard)*

```
+-----------------------------------------------------------------------+
|                       LIVE SWITCHING RULES                            |
| 1. PRAISE & WORSHIP:                                                  |
|    • Cut on the downbeat / rhythm of the drums/bass.                  |
|    • Cycle: Cam 1 (Wide) ➔ Cam 3 (Instruments/Gimbal) ➔ Cam 2 (Lead) |
|    • Hold time: 4 - 8 seconds per shot.                               |
|                                                                       |
| 2. SLOW WORSHIP & PRAYER:                                             |
|    • Smooth Cross-Dissolve only (1.0s transition).                     |
|    • Hold shots for 12 - 20 seconds. Avoid fast, frantic cuts.        |
|                                                                       |
| 3. PREACHING / SERMON:                                                |
|    • 75% on Cam 2 (Medium Close-Up on Preacher).                      |
|    • 15% on Cam 3 (Side Profile / 45° Angle).                         |
|    • 10% on Cam 1 (Wide Stage when preacher moves broadly).           |
|                                                                       |
| 4. COMMS STANDARD:                                                    |
|    "Ready Cam [X]... Take Cam [X]!"                                   |
|    (NEVER cut to a moving, zooming, or out-of-focus camera!)          |
+-----------------------------------------------------------------------+
```

## 🟩 CARD 2: Camera Operator Cheat Sheet
*(Attach to the pan-bar handle of Camera 1, Camera 2, and Gimbal monitor)*

```
+-----------------------------------------------------------------------+
|                     CAMERA OPERATOR DISCIPLINE                        |
|                                                                       |
| 1. HEADROOM:                                                          |
|    Leave 1 to 2 inches of space above the speaker's head.             |
|    Never push the head to the ceiling or cut off the forehead.        |
|                                                                       |
| 2. EYE LEVEL & RULE OF THIRDS:                                        |
|    Align the speaker's eyes with the upper horizontal third-line.     |
|                                                                       |
| 3. WHEN YOUR TALLY LIGHT IS RED (LIVE ON AIR):                        |
|    • LOCK YOUR TRIPOD / HOLD RIG ROCK STEADY.                         |
|    • DO NOT ZOOM.                                                     |
|    • DO NOT HUNT FOR FOCUS.                                           |
|    • If the speaker moves, follow with a slow, smooth, buttery pan.   |
|                                                                       |
| 4. WHEN YOUR TALLY LIGHT IS OFF (OFF AIR):                            |
|    • Find your next shot immediately.                                 |
|    • Lock focus, check exposure, and hold ready for the Director.     |
+-----------------------------------------------------------------------+
```

```
|     • Check: Is audio distorted? Adjust TV volume down if buzzing.    |
|                                                                       |
| [ ] T - 15 MIN: PREACHER MIC BATTERY AUDIT                            |
|     • Bodypack transmitter battery level: MUST SHOW FULL BARS.        |
|     • Receiver RF link: Solid GREEN.                                  |
|     • Emergency drawer: Verify 8 fresh AA batteries are present.      |
+-----------------------------------------------------------------------+
```

## 🟦 CARD 4: Emergency Live Stream Troubleshooting Card
*(Tape directly beside the Streaming PC monitor)*

```
+-----------------------------------------------------------------------+
|                    STREAM EMERGENCY PROTOCOLS                         |
|                                                                       |
| 1. IF YOUTUBE STREAM DROPS / INTERNET CUTS:                           |
|    • DO NOT STOP LOCAL RECORDING. Local recording must continue!      |
|    • Switch streaming PC to the Church Mobile Hotspot backup Wi-Fi.   |
|    • Click "Start Streaming" in OBS once connection re-establishes.   |
|                                                                       |
| 2. IF A CAMERA FEED GOES BLACK:                                       |
|    • Instantly switch to CAM 1 (Wide) or FULL-SCREEN LOGO SLIDE.      |
|    • Check SDI/HDMI cable at switcher port. Re-seat firmly.           |
|                                                                       |
| 3. IF PRESENTATION / LYRICS FREEZE:                                   |
|    • Hit "CLEAR LOWER THIRD" on switcher immediately.                 |
|    • A clean video feed is 100x better than frozen, wrong lyrics.     |
|                                                                       |
| 4. IF AUDIO DISTORTS / BUZZES:                                        |
|    • Immediately drop Ambient Room Mics fader to zero.                |
|    • Check master OBS stream limiter (-1.0 dB ceiling).               |
+-----------------------------------------------------------------------+
```
