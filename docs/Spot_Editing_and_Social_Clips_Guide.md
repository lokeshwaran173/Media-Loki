## 1. What is "Spot Editing"?
Spot Editing is the process of capturing, trimming, branding, and captioning a **30 to 60-second high-impact sermon or worship moment** during or immediately following the 1st Service.

Posting within 2–4 hours after Sunday service captures the highest engagement while the message is still fresh in the hearts of the congregation.

---

## 2. In-Service Listening & Timestamp Logging (T - 0 to T + 90 min)

While the 1st service is happening, the Spot Editor sits at the editing desk wearing headphones and actively listens for:
1. **The "Punchline" / Core Takeaway:** A 30–45 second continuous statement where the pastor speaks with conviction.
2. **The Encouragement / Prophetic Word:** A declaration over families, health, finances, or faith.
3. **The Practical Illustration / Story:** A relatable testimony or life lesson.

### Timestamp Log Sheet Example:

## 3. Editing Standards & Specifications

```
+------------------------------------+
|            [ 9:16 VERTICAL ]       |
|                                    |
|       [ FLAG LOGO (Top) ]          |
|                                    |
|           (  o . o  )              |
|          /    |    \               |
|         [ Preacher Video ]         |
|                                    |
|      "YOUR STORM IS NOT            |  <-- Animated / High-Contrast
|        YOUR TOMB..."               |      Captions in Center-Lower 3rd
|                                    |
|   [ @FLAGChurch Social Handle ]    |
+------------------------------------+
```

### Technical Specs:
* **Aspect Ratio:** 9:16 Vertical (1080 x 1920 pixels) for Instagram Reels, YouTube Shorts, and WhatsApp Status.
* **Duration:** 30 to 59 seconds (optimal sweet spot is 40–50 seconds).
* **Audio Normalization:** Normalize dialogue to **-14 LUFS** to sound loud and clear on mobile phone speakers without clipping.
* **Captions (Crucial):** Over 75% of social media users watch without headphones. 
  * Use bold, clean fonts (e.g., Montserrat, Poppins, or Bebas Neue).
  * Color: White text with yellow or green keyword highlights and black stroke/shadow.
  * Placement: Middle-lower third (never at the very bottom where Instagram UI buttons cover the words).

## 4. 45-Minute Post-Service Delivery Workflow

```
[ 1st Service Ends ] 
       │
[ 10 mins: Ingest Master MP4 to SSD ]
       │
[ 15 mins: Cut Selected 45s Timestamp & Crop to 9:16 ]
       │
[ 10 mins: Generate Auto-Captions & Add FLAG Branding ]
       │
[ 05 mins: Export MP4 (H.264, 15 Mbps Bitrate) ]
       │
[ 05 mins: Upload to Shared Google Drive / WhatsApp for Outdoor & Web Media ]
```

## 5. Handoff to Outdoor & Web Media
Once exported, save the clip to the shared folder:

Send a quick WhatsApp message to the Web and Outdoor leads:
