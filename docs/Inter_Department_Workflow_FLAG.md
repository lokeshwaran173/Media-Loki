# FLAG Church - Inter-Department Media Workflow
**Departments:** Indoor Media | Outdoor Media | Web Media  
**Church:** Full Life Centre AG Church (FLAG)

---

## 1. Overview & Collaboration Map

The three media departments at FLAG work as an interconnected pipeline. Indoor Media captures the primary church events and messages, which are subsequently packaged, edited, and distributed by Outdoor and Web Media.

```
       +---------------------------------------------+
       |             INDOOR MEDIA                    |
       |  - Sunday Live Streams                      |
       |  - High-Resolution Master Audio/Video ISOs   |
       |  - Preacher / Worship High-Bitrate Cuts     |
       +---------------------------------------------+
                      |                      |
      [Raw Footage & Master Audio]      [Stream Links, Embeds & Metadata]
                      |                      |
                      v                      v
+-------------------------------+  +----------------------------------+
|        OUTDOOR MEDIA          |  |           WEB MEDIA              |
| - Short Film Integrations     |  | - Website Live Embeds & Pages    |
| - Sermon Highlight Reels / 4K |  | - Sermon Audio Podcast Feeds     |
| - Song Video Cutdowns         |  | - Web App Sermon Notes / Slides  |
| - Promo / Social Media Reels  |  | - Archive Search & Cataloging    |
+-------------------------------+  +----------------------------------+
```

## 2. Indoor Media ➔ Outdoor Media Handoff

Outdoor Media handles creative shoots, song videos, short films, and high-impact social edits. Indoor Media provides the foundation footage.

### A. Folder & File Naming Structure
Every Sunday, Indoor Media exports and stores files in the following standardized folder format:

```
FLAG_MEDIA_SERVER/
└── YYYY-MM-DD_Sunday_Service/
    ├── 01_Full_Master_Stream_1080p.mp4
    ├── 02_Sermon_Only_Clean.mp4
    ├── 03_Worship_Only_Clean.mp4
    ├── 04_Broadcast_Audio_Master.wav
    └── 05_Camera_ISOs/ (Optional / When requested)
```

### B. Highlight Timestamp Log
Within 4 hours after service, the Indoor Media team leader sends a brief bulleted list to the Outdoor Media lead:
* **Example:**
  * *00:24:15 - 00:29:40:* Powerful prophetic declaration during worship (High energy).
  * *00:48:10 - 00:51:30:* Main sermon climax (Ideal for 60-second Instagram Reel / YouTube Short).
  * *01:12:00 - 01:14:20:* Inspiring closing altar testimony.

### C. Shared Gear Protocol
* Any cameras, wireless mics, or lighting borrowed by Outdoor Media for shoots (short films, song covers) must be:
  1. Signed out on the **Equipment Register**.
  2. Inspected for clean lenses, charged batteries, and formatted SD cards.
  3. Returned and checked back into the Indoor Media storage cabinet no later than **Friday 6:00 PM** before Sunday service.

## 3. Indoor Media ➔ Web Media Handoff

Web Media develops and maintains the church website, streaming portal, and web application. Indoor Media supplies the live broadcast data and archival content.

### A. 24 Hours Before Service (Saturday Morning)
* Indoor Media creates the upcoming YouTube / Facebook scheduled stream and sends Web Media:
  * **Stream URL & RTMP / Embed Code**
  * **Service Title:** e.g., *"Sunday Worship Service - Rev. Pastor [Name] | FLAG Church"*
  * **Theme / Scripture Reference:** e.g., *"Walking in Dominion (Romans 8:31-39)"*
  * **Official Thumbnail Graphic**

### B. During Service
* Web Media embeds the player directly into the church website / web app so online members can watch without distraction.
* If streaming connection parameters or links fail, Indoor Media immediately pings the Web Media team with the fallback stream URL.

### C. Post-Service Archival Handoff (Sunday Evening)
* Indoor Media provides:
  * YouTube Video ID / Clean Link.
  * Exact Sermon Start and End timestamps (for chapter markers on the web app).
  * PDF of the preacher's sermon slides (for members to download on the church portal).
